PixelPet is a small pixel pet that lives on your desktop. It walks along the bottom of the screen, naps, and can be petted, played with and fed. One file, no installer, no internet.

**Downloads**

- **Windows:** `PixelPet.exe`. Run it from anywhere.
- **macOS (Intel and Apple Silicon):** `PixelPet.dmg`. Open it and drag PixelPet to Applications.
- **Linux:** `PixelPet-x86_64.AppImage`. Make it runnable (`chmod +x PixelPet-x86_64.AppImage`), then run it. It needs an X11 desktop or a Wayland one with XWayland, and the X keyboard library every desktop has (`libxkbcommon-x11`).

**The first launch shows a warning, once**

PixelPet isn't signed yet, so each system asks before running it the first time:

- **Windows:** "Windows protected your PC". Click **More info**, then **Run anyway**.
- **macOS:** "PixelPet can't be opened". Right-click PixelPet in Applications, choose **Open**, then **Open** again. (Run it from Applications, not from the dmg, or launch-on-startup can't be turned on.)
- **Linux:** no warning.

Right-click the pet for its menu: which pet, size, opacity, what happens over fullscreen apps, launch on startup, and quit.
